Privacy Policy – Publication Sync

Last updated: 16 November 2026

Publication Sync is a personal script that runs only on its author's computer.

  • Data accessed: it uses the Google Drive scope drive.file, which only gives access to files and folders the script itself created. It cannot see any other files in Google Drive.
  • Use: the script uploads local files to the user's own Google Drive folder and reads their names and checksums to decide which files need updating.
  • Storage and sharing: no data is sent to, stored on, or shared with any server or third party other than Google Drive itself. The login token is stored only on the local computer.
  • Revoking access: access can be removed at any time at myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
